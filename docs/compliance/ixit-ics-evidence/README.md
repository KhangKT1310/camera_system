# IXIT and ICS Evidence

## Purpose

This directory stores implementation conformance statements, interface references, security evidence, and review artifacts needed to demonstrate alignment with QCVN 11:2026/BCA.

## What Belongs Here

* IXIT or ICS drafts.
* Test reports, evidence indexes, and traceability notes.
* Screenshots, captures, configuration records, and sign-off material tied to specific controls.

## What Must Not Be Placed Here

* Production secrets, live customer data, or full raw recordings.
* Unreviewed claims that mark compliance as achieved.
* Evidence without control references, dates, or ownership.

## Security and Compliance Notes

Evidence must map back to the control matrix, interface inventory, and threat model. Any security-relevant change should add or update evidence here and remain in `Draft`, `TODO`, or reviewed status until validated by humans.

## Cross-Platform Notes

Capture platform-specific evidence separately when secure storage, crypto support, debug controls, or OTA behavior differ by chip or operating system.
